Evernote Archive · Windows guide

Make a private copy of your notes

Use the copy to read your notes, save a backup, or try another notes app.

Do not open Evernote for these steps. This tool works from copied files. Never import or restore the copy into your original Evernote account.

The Windows backup route is a preview. A helper must check its report before you rely on the result. It cannot promise that everything in your account is stored on either computer.

1. Get ready on Windows

  1. Download the Windows ZIP from the GitHub release page. Right-click the ZIP and choose Extract All.
  2. Install Node.js for Windows, version 22.13 or later. Ask your helper to do this one-time setup if needed.
  3. In the extracted folder, double-click Start Evernote Archive.cmd. The first run downloads the app's required libraries. Your browser opens Evernote Archive.
  4. Plug in a private USB backup drive. It must have a different drive letter from the drive containing the Evernote data.

Keep the extracted app folder. Your readable library is saved inside it. Use a private drive with enough free space for several copies of the notes and attachments.

You are ready when the archive opens in your browser. It does not ask for an Evernote password.

After this setup, copying and exporting need no internet. Do not open, close, sign into, or sync Evernote to prepare it.

2. Copy the Windows data

If you already have .enex export files, skip to step 3. Otherwise, have your helper do these steps with you.

Make the backup

  1. Right-click Backup Windows Evernote.cmd. Choose Run as administrator.
  2. Enter a new folder on your private backup drive, such as E:\Evernote-PC1-backup. Use your actual drive letter.
  3. Check the source Windows user and the destination shown in the window. Type BACKUP only when both are correct.
  4. Wait for Backup verified. Keep the backup folder private and unchanged.

If you use another administrator's password, the helper may find that administrator's Evernote folder. Stop if the displayed Windows user is wrong.

Make export files from the backup

  1. Double-click Export Windows Backup.cmd normally.
  2. Enter the backup folder from the previous step.
  3. Enter a different new folder for the exports, such as E:\Evernote-PC1-export.
  4. Open READ ME.txt in the result. Have your helper review export-report.json.

The enex folder holds the readable export files. original-backup keeps the complete copied input.

Repeat on the second Windows computer using different folder names. Keep both backups separate. Do not combine them or discard a copy until your helper compares the results.

If the tool reports missing content or an error

Keep the window open and keep all the files. Show your helper the message. Do not open Evernote to download missing notes or attachments.

The second Windows backup may contain additional material. Neither backup can prove that all cloud-only material was captured.

The detailed Windows guide describes supported formats and the material that remains in the raw backup.

3. Read and check your copy

  1. In Evernote Archive, choose Add notebooks, then Choose ENEX files.
  2. Select the files in your export's enex folder. Give each file the notebook name shown in the report.
  3. Choose Add to archive. Wait for each file to finish.
  4. Open a notebook and a note. Try search and a tag. Check some images and attachments.
  5. For each imported file, choose Take this notebook, then Complete archive. Save the ZIP on your backup drive.

To practise first, use examples/sample.enex from the download. It contains two invented notes. Keep this practice library separate from your real library.

Compare notebook and note counts with your helper. Review every failure and conversion notice. Reading these copies does not contact Evernote.

Links inside notes are inactive in this reader. Downloaded attachments opened in other apps can contact outside services. Use offline viewers when needed.

Read on your iPhone or iPad

  1. On the Windows PC, double-click Start on iPhone.cmd.
  2. In the archive, choose Use on iPhone.
  3. Connect your iPhone or iPad to the same trusted Wi-Fi as the PC.
  4. Open the private link in Safari. Keep the PC awake while you read.

The same link can open in a browser on your other Windows PC. Keep the link private. This is the archive reader, not the Evernote app.

Optional: try another notes app

Joplin runs on Windows, iPhone and iPad. Try a copied notebook before deciding to move.

  1. Install Joplin on one Windows PC. Use a fresh local library for the trial.
  2. Choose File, then Import, then ENEX. Select a copied export file.
  3. Check the notes, tags, dates, formatting and attachments. Do not follow links back to Evernote.
  4. If you want to continue, import the remaining files on this PC. Keep your backups.
  5. Follow Joplin's sync instructions to use the same new library on your other devices.

Do not import every file again on each device. Let Joplin sync the library. Your original Evernote account can stay as it is.

Formatting, internal links and other features may differ. See Joplin's import limits. This package has not been tested against your notes or a live Joplin installation.

This guide works offline and loads no external images or scripts. External links open only when you select them.
